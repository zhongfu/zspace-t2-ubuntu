# ZSpace T2 documentation

* `tinkering.md` — open the case, serial console, maskrom button, SD boot.
* `building.md` — the four-repository layout, host setup, build order, firmware, Docker.
* `using.md` — install, provisioning, backup.
* `releasing.md` — build the artefacts on a tag and publish a release.

The repository root `README.md` has the layout and entry points, and
`components.lock` names the component artefacts this image is built from.
